## Research Vision
My research focuses on building **dependable and intelligent systems** (Dependable AI Systems) spanning compute–chip–robot. The goal is to ensure safety, reliability, and security for the super-smart society by addressing critical challenges in **IC testing**, **system-level dependability**, **secure design**, and **AI-chip reliability**.

---

## <a id="automotive"></a>Functional Safety & Automotive Systems

### Core Focus
- Enabling high-quality **automotive functional safety** compliance with ISO 26262
- Developing **Power-On Self-Test (POST)** and **on-line self-diagnosis (BISD)** technologies
- Multi-cycle testing and fault detection strengthening

### Key Contributions
- Proposed automotive MCU self-test architectures enabling ISO 26262 compliance in large-scale systems
- Developed multi-cycle test point insertion techniques for improved fault coverage
- Created capture-pattern control methods addressing fault detection degradation in multi-cycle BIST
- Collaborated with Renesas Electronics on production automotive microcontroller implementations

### Representative Publications
- IEEE Design and Test Magazine, 2018 - "Automotive Functional Safety Assurance by POST with Sequential Observation"
- IEEE Asian Test Symposium (ATS), 2018 - Multi-cycle BIST fault detection enhancement

## <a id="ictest"></a>VLSI Testing, Diagnosis & Dependable Design

### Core Focus
- **Low-power logic BIST** and field testing methodologies
- **Fault diagnosis** techniques (stuck-at, delay, bridging faults)
- **Testability design** for complex systems
- **Power-aware testing** considering IR-drop and thermal effects

### Key Contributions
- Scan-out power reduction methods for multi-cycle BIST
- Fault diagnosis considering hazards and path delay variations
- Lightweight pattern partitioning algorithms for field test
- Machine learning-based test point selection (Graph Convolutional Networks + Reinforcement Learning)
- Spatio-temporal GCN models for functional fault impact prediction

### Representative Publications
- ACM Transactions on Design Automation (2026) - Spatio-temporal GCN for fault prediction
- ACM Transactions on Design Automation (2023) - Test Point Insertion for Multi-Cycle POST
- IEEE Transactions on Emerging Topics in Computing (2017) - Flexible scan power control

## <a id="security"></a>Secure Design & Lightweight Authentication

### Core Focus
- **IoT device authentication** and secure testing
- **Physical Unclonable Functions (PUF)** resistant to machine learning attacks
- **JTAG security** and boundary scan protection

### Key Contributions

- Comprehensive JTAG security threat analysis

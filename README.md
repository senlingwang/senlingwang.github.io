# Senling Wang - Personal Academic Website

This is the source repository for **Dr. Senling Wang's** personal academic website, hosted at [senlingwang.github.io](https://senlingwang.github.io).

## About

Dr. Senling Wang is a **Lecturer** at Ehime University, Graduate School of Science and Engineering. His research focuses on:

- **Dependable VLSI Systems** — IC testing, diagnosis, and testability design
- **Automotive Functional Safety** — ISO 26262 compliance, power-on self-test (POST)
- **Chiplet & 3D Integration** — Reliability and testing of advanced semiconductor architectures
- **AI Chip Reliability** — Edge processors, neural network implementations, and secure design
- **Secure Systems** — Lightweight authentication, PUF design, IoT security

## Getting Started

This site is built using **Jekyll** and **GitHub Pages**. To run locally:

```bash
bundle install
bundle exec jekyll serve
```

The site will be available at `http://localhost:4000/`.
